Step-by-step Guide

How to Animate a Sprite

Coding အတွေ့အကြုံ လုံးဝမရှိသေးတဲ့ သားသားမီးမီးတို့အတွက် Blocks လေးတွေကို Puzzle ဆက်သလို ဆက်ပြီး ဇာတ်ကောင် (Sprite) လေးတွေကို အလိုအလျောက် လှုပ်ရှားစေမယ့် နည်းလမ်းဖြစ်ပါတယ်။

1 ပွဲစဖို့ ပြင်ဆင်မယ် (Events)

Animation တစ်ခုစတင်ဖို့အတွက် အစပြုမယ့် ခလုတ်တစ်ခု လိုအပ်ပါတယ်။ Scratch မှာ အစိမ်းရောင်အလံ (Green Flag) လေးကိုနှိပ်တာနဲ့ စတင်အလုပ်လုပ်ဖို့ Event Block ကို အရင်ဆွဲထည့်ပါမယ်။

  • When [Green Flag] clicked

2 လှုပ်ရှားမှု ထည့်မယ် (Motion)

Sprite လေးကို ရှေ့ကိုရွေ့စေချင်ရင် Motion category ထဲက "Move" block ကို သုံးပါမယ်။ လှမ်းမယ့် ခြေလှမ်းအရေအတွက် (Steps) ကို ကိုယ်တိုင် ပြင်လို့ရပါတယ်။

  • move (10) steps

3 ရုပ်ထွက်ပြောင်းမယ် (Looks)

ခြေလှမ်းလှမ်းသလို သဘာဝကျကျဖြစ်ဖို့ Sprite ရဲ့ ပုံစံ (Costume) ကို ပြောင်းပေးရပါမယ်။ ဒါမှသာ လမ်းလျှောက်နေတဲ့ Animation အစစ်နဲ့ တူလာမှာပါ။

  • next costume

4 ထပ်ခါထပ်ခါ လုပ်ခိုင်းမယ် (Loops)

လုပ်ဆောင်ချက်တွေကို တစ်ခါတည်းနဲ့ မရပ်ဘဲ ဆက်တိုက်အလုပ်လုပ်စေချင်ရင် Control category ထဲက "Forever" လိုမျိုး Looping block တွေ အသုံးပြုပေးရပါတယ်။

  • forever
  • wait (0.1) seconds
