How to Animate Your First Sprite!

Coding အတွေ့အကြုံ လုံးဝမရှိသေးတဲ့ သားသားမီးမီးတို့အတွက် Legos/Puzzle တွဲဆော့သလိုမျိုး colorful block လေးတွေဆက်ပြီး မိမိနှစ်သက်တဲ့ Sprite ဇာတ်ကောင်လေးတွေကို သက်ဝင်လှုပ်ရှားအောင် ဖန်တီးလိုက်ကြရအောင်!

1 Sprite Move Forward and Talking

Animation တစ်ခုစတင်ဖို့အတွက် အစပြုမယ့် ခလုတ်တစ်ခု လိုအပ်ပါတယ်။ Scratch မှာ အစိမ်းရောင်အလံ (Green Flag) လေးကိုနှိပ်တာနဲ့ စတင်အလုပ်လုပ်ဖို့ Event Block ကို အရင်ဆွဲထည့်ပါမယ်။

  • Events: When [Green Flag] clicked
  • Motion: move 10 steps
  • Looks: say "Hey, ready?" for 2 seconds
  • Looks: say "Let's go!"

2 Explain Costumes (ဝတ်စုံပုံစံများ)

ခြေလှမ်းလှမ်းသလို သဘာဝကျကျဖြစ်ဖို့ Sprite ရဲ့ ပုံစံ (Costume) ကို ပြောင်းပေးရပါမယ်။ ဒါမှသာ လမ်းလျှောက်နေတဲ့ Animation အစစ်နဲ့ တူလာမှာပါ။

  • Costumes Tab: Go to Costumes tab (ဘယ်ဘက်အပေါ်ဒေါောင့်)
  • Costume 1 & 2: Compare walking poses (ခြေလှမ်းပုံစံ နှစ်မျိုးကို နှိုင်းယှဉ်ပြပါ)

3 Sprite Walking and Speaking

Sprite လေးကို လမ်းလျှောက်ရင်း စကားပြောအောင် Motion၊ Looks နဲ့ Costume block တွဲသုံးပါမယ်။

  • Events: When [Green Flag] clicked
  • Motion: move 10 steps
  • Looks: next costume
  • Looks: say "I'm running" for 2 seconds

4 Explain X and Y Coordinates (တည်နေရာသတ်မှတ်ခြင်း)

Scratch Stage ပေါ်မှာ Sprite ဘယ်နေရာမှာရှိလဲဆိုတာကို X (ဘယ်/ညာ) နဲ့ Y (အပေါ်/အောက်) တန်ဖိုးတွေနဲ့ သတ်မှတ်ပါတယ်။

  • Motion: go to x: (0) y: (0) (Center point)
  • X-axis: Left (-) to Right (+)
  • Y-axis: Down (-) to Up (+)

5 Moving Sprite with Keyboard (Keyboard ဖြင့် Sprite ကို ရွှေ့ခြင်း)

Keyboard ပေါ်က Arrow keys (မျှားခလုတ်များ) ကို အသုံးပြုပြီး Sprite လေးကို ဘယ်၊ ညာ၊ အပေါ်၊ အောက် စိတ်ကြိုက် ရွှေ့လျားအောင် Event block များနှင့် Motion block များကို တွဲဖက် အသုံးပြုပါမယ်။

  • Events: When [right arrow key] pressed
  • Motion: change x by (10) (ညာဘက်သို့ သွားရန်)
  • Events: When [left arrow key] pressed
  • Motion: change x by (-10) (ဘယ်ဘက်သို့ သွားရန်)
  • Events: When [up arrow key] pressed
  • Motion: change y by (10) (အပေါ်သို့ သွားရန်)
  • Events: When [down arrow key] pressed
  • Motion: change y by (-10) (အောက်သို့ သွားရန်)

5 Jumping Sprite When Up Arrow Key Pressed (ခုန်ကျော်ခြင်း)

Keyboard ပေါ်က Up Arrow ခလုတ်ကို နှိပ်လိုက်တဲ့အခါ Sprite လေးက အပေါ်ကို ခုန်တက်ပြီး အောက်ကို ပြန်ဆင်းလာအောင် Y-axis တန်ဖိုးကို ပြောင်းလဲပေးရပါမယ်။

  • Events: When [up arrow] key pressed
  • Control: repeat (10)
  • Motion: change y by (10)
  • Control: repeat (10)
  • Motion: change y by (-10)
