ကစားရင်း သင်ယူမယ်၊ သင်ယူရင်း ဖန်တီးမယ်!

မိမိတို့ရဲ့ သားသားမီးမီးများကို ဖုန်းနဲ့ Game ပဲ ဆော့မနေစေဘဲ Game တွေကို ကိုယ်တိုင်ဖန်တီးနိုင်တဲ့ Developer အငယ်စားလေးများ ဖြစ်လာဖို့ ပြင်ဆင်ပေးလိုက်ပါ။

AGES 6–10

Scratch Programming (Level-1)

Coding ဆိုတာ ခက်ခဲပါသလား?

မခက်ပါဘူး! Scratch ဆိုတာ စာတွေ အများကြီး ရိုက်နေစရာမလိုဘဲ Blocks လေးတွေကို ပဟေဠိ (Puzzle) ဆက်သလို ဆက်ပြီး ခိုင်းစေရတဲ့ Visual Programming ဖြစ်တာကြောင့် Coding ကို အခုမှ စတင်ထိတွေ့မယ့် သားသားမီးမီးတို့အတွက် အသင့်တော်ဆုံးပါပဲ။ 🌟

ဒီသင်တန်းမှာ ဘာတွေ သင်ယူရမှာလဲ?

  • Scratch ရဲ့ အခြေခံ Tool များအသုံးပြုပုံ
  • Move, Looks & Control Blocks များ
  • Game တွေမှာ အရေးပါတဲ့ Variables, Looping & Operators များ
  • Graphics Effect များအသုံးပြုပြီး လှပအောင် ဖန်တီးပုံ
  • Game Title Screen နဲ့ Score System (ရမှတ်ရေတွက်နည်း) ပြုလုပ်ပုံ
  • Sprite (ဇာတ်ကောင်) များကို အလိုအလျောက် လှုပ်ရှားစေပုံ

ဘာကြောင့် ဒီသင်တန်းကို ရွေးချယ်သင့်တာလဲ?

အလွတ်ကျက် သင်ကြားမှု မဟုတ်ဘဲ Animation တွေ၊ Game Project တွေကို Hands-on (ကိုယ်တိုင်) ဖန်တီးရင်း သင်ကြားရမှာဖြစ်လို့ ပျင်းစရာ လုံးဝမကောင်းဘဲ ကလေးတို့ရဲ့ Logic Thought (ယုတ္တိဗေဒနည်းကျ တွေးခေါ်မှု) နဲ့ Problem Solving Skills (ပြဿနာဖြေရှင်းနိုင်စွမ်း) ကို မြှင့်တင်ပေးနိုင်ပါတယ်။

AGES 10–18

ကလေးများအတွက် Python Programming သင်တန်း

အသက် (၆) နှစ်မှ (၁၈) နှစ်အထိ ကလေးများနှင့် လူငယ်များအတွက် အထူးသီးသန့် ရေးဆွဲထားသော ကလေးငယ်များ၏ စဉ်းစားတွေးခေါ်နိုင်စွမ်း၊ ပြဿနာဖြေရှင်းနိုင်စွမ်းနှင့် တီထွင်ဖန်တီးနိုင်စွမ်းများကို မြှင့်တင်ပေးနိုင်မည့် သင်တန်းဖြစ်ပါသည်။

သင်တန်းတွင် ဘာတွေသင်ယူရမလဲ။

  • Coding ၏ အခြေခံသဘောတရားများကို ပျော်ရွှင်စွာ လေ့လာခြင်း
  • Python တကယ့် Programming Text စာကြောင်းများ စတင်ရေးသားခြင်း
  • Variable, Loop, Condition စသည့် အရေးကြီးသော Logic များ သင်ယူခြင်း
  • ဉာဏ်စမ်းဂိမ်းများ (Quiz Games) နှင့် စာသားအခြေပြု Mini-Games များ ရေးဆွဲခြင်း
  • Python Structure များ၊ Functions နှင့် Data Structures များ အသေးစိတ် လေ့လာခြင်း
  • Website ရေးသားခြင်း နှင့် Artificial Intelligence (AI) အခြေခံသဘောတရားများအား မိတ်ဆက်ပေးခြင်း

Academic skills

Algorithmic thinking လက်တွေ့ဘဝပြဿနာတွေအတွက် ဖန်တီးမှုရှိပြီး ထိရောက်တဲ့ ဖြေရှင်းနည်းတွေကို ရှာဖွေခြင်း။
ပြဿနာဖြေရှင်းခြင်း ကလေးတွေဟာ အမှားတွေကို ကျရှုံးမှုဆိုတာထက် အခွင့်အရေးတစ်ခုအဖြစ်သာ မြင်တတ်သွားပါတယ်။
Analytic နဲ့ logical thinking Coding က ကလေးတွေကို တကယ့်ဥပမာတွေရော graphic visual ဥပမာတွေကနေတစ်ဆင့် အယူအဆကောက်နုတ်ချက်တွေကို နားလည်သွားအောင် ကူညီပေးပါတယ်။
STEM ကိုပိုပြီး နားလည်သဘောပေါက်လာခြင်း ကလေးတွေရဲ့စွမ်းဆောင်ရည်တွေက အလျင်အမြန်တိုးလာတာကြောင့် အဆင့်တွေပိုပြီးကောင်းလာပါတယ်။

Soft skills

ဖန်တီးနိုင်စွမ်း ကလေးတွေရဲ့ ဖန်တီးနိုင်စွမ်းကို အကြီးအကျယ်တိုးတက်စေမယ့် အကောင်းဆုံးဖြစ်နိုင်ခြေ နည်းလမ်းတစ်ခု ဒါမှမဟုတ် တီထွင်မှုတစ်ခုကို ရှာဖွေပါ။
အာရုံစူးစိုက်မှုနဲ့ တိကျမှု coding သင်နေစဥ်မှာ ကလေးတွေဟာ မှန်ကန်တဲ့အစီအစဥ်နဲ့ တိကျတဲ့ commands ပေးပုံကို သင်ရမှာဖြစ်ပြီး ဒါဟာ သူတို့ရဲ့ အာရုံစူးစိုက်မှုကို တိုးသွားစေပါတယ်။
အာရုံစူးစိုက်ခြင်းနဲ့ ဇွဲရှိခြင်း ပိုပြီးရှုပ်ထွေးတဲ့ ဂိမ်းတွေဟာ code တွေပိုပြီးလိုအပ်ပါတယ်၊ ဒါကြောင့် အချိန်ပိုကုန်ပြီး ပိုပြီးအာရုံစူးစိုက်ရပါတယ်။
ကိုယ့်ဘာသာယုံကြည်မှု ရှုပ်ထွေးတဲ့ code တစ်ခုကို ဖန်တီးရတာက ကလေးတွေ တကယ်ကိုဂုဏ်ယူရမယ့် မဟာအစွမ်းတစ်ရပ်ဖြစ်ပါတယ်။

Visual coding ကနေ text based programming ကို အလွယ်တကူပြောင်းလို့ရအောင် ကျွန်တော်တို့ရဲ့ ထူးခြားတဲ့ပညာရေးပလက်ဖောင်းကို တီထွင်ထားပါတယ်။

Blox coding

Building blocks တွေနဲ့ coding ပညာရေးကို စတင်ပါတယ်။ ကျွန်တော်တို့ရဲ့ ထူးခြားတဲ့ visual coding နည်းက ဘယ်အသက်အရွယ်မဆို အမြဲသင့်တော်ပါတယ်။

Mix coding

ဒုတိယအဆင့်အနေနဲ့ ကျောင်းသားတွေက MIX mode နဲ့ codes တွေစရေးရမှာဖြစ်ပါတယ်၊ အဲဒီမှာ သူတို့အနေနဲ့ building blox နဲ့ text-based languages ကို အပြိုင်တွေ့ရမှာဖြစ်ပါတယ်။

Text coding

visual blocks ကို သူတို့သေချာတတ်ကျွမ်းသွားတာ သေချာပြီဆိုတာနဲ့ ကျွန်တော်တို့က နောက်ထပ် text-based programming ဘာသာရပ်တွေဖြစ်တဲ့ Python၊ Unity၊ Godot၊ C# တို့ကို ဆက်ပြီးသင်ပေးပါတယ်။
